# Daily Coding

Solving one programming problem every day.

## Purpose
To build consistency, better understanding of algorithms and data structures, and improve problem-solving skills through daily practice.

## Structure
Each solution file contains:
- Problem statement
- Implementation
- Complexity analysis
- Key insights and reflections

Files are named sequentially: `001_problem_name.py`, `002_problem_name.py`, etc.

## How to Use
1. Solve one problem daily
2. Create a new file in `problems/` with sequential numbering
3. Include problem statement, solution, and reflections
4. Commit with a descriptive message

## Problem Sources
- LeetCode
- Daily Coding Problem
- Advent of Code
- Project Euler
- Personal challenges
- Coding Interviews from Big Companies
